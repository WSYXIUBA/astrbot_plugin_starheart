# StarHeart

[English](./README.en.md) · **中文**

AstrBot 的长期记忆插件：把对话整理成本地记忆，在需要时提供给模型参考，并维护人物 / 群聊画像、关系与表达习惯。

| | |
| --- | --- |
| 插件名 | `astrbot_plugin_starheart` |
| 版本 | `1.0.5` |
| 作者 | 肆一纸心 |
| 仓库 | <https://github.com/WSYXIUBA/astrbot_plugin_starheart> |
| 适配器 | `aiocqhttp`（OneBot v11） |
| AstrBot | >= 4.24.0 |

## 机制

- 旁听消息事件，不拦截、不改写原有回复。
- 记忆在 LLM 请求前注入，仅取与当前话题相关的条目。
- 主动开口可选，默认关闭，受静默时段、每日额度与名单约束。

## 功能

- 长期记忆：对话整理为条目存入本地库；长期未访问的记忆会衰减并归档。
- 相关回忆：每轮按话题召回记忆。
- 向量库多代：换 embedding 模型后自动新建一代并回填，建满再切换；旧代保留，换回旧模型直接复用。
- 人物 / 群聊画像：按人、按群生成并更新。
- 关系与好感：互动累积关系值，影响回复语气。
- 表达习惯：从对话中学习表达方式，在回复中参考。
- 主动开口：静默一段时间后可自行发起对话（可选）。
- 撤回记录：保留被撤回消息的正文与图片。
- 面板：记忆图谱、记忆库、消息事件、人格、设置。
- 升级兼容：升级后配置与面板项不丢失。

## 安装

市场搜索 `StarHeart`，或用「从 URL 安装」填仓库地址；手动安装把 `astrbot_plugin_starheart` 放进 `data/plugins/`。

## 数据

全部数据在本地 `data/plugin_data/astrbot_plugin_starheart/`；除你配置的模型接口外，不向第三方发送。
